tlmnet documentation
====================

``tlmnet`` provides exact Mixed-Integer Linear Programming (MILP) solvers for Quantized Statistical Learning with Ternary Linear Models (TLMs) with weights with weights :math:`w_j \in \{-1, 0, 1\}`.

# Contributing to calfcv

Thank you for your interest in `calfcv`!

`calfcv` is developed, maintained, and supported directly by **Carlson Research, LLC**. To ensure a focused development path and maintain strict quality standards across our statistical software, **we are not accepting external code Pull Requests (PRs) at this time**.

However, feedback, bug reports, and metric discrepancy findings from the research community are always welcome and greatly appreciated!

## How You Can Help

### Reporting Bugs & Discrepancies

If you encounter a bug, calculation discrepancy, or Scikit-Learn pipeline incompatibility while using `calfcv`, please open an issue on our GitHub repository.

To help us resolve the issue quickly, please include:

* **A clear, descriptive title**.
* **Steps to reproduce the issue** (including specific code snippets, seed values, or sample datasets).
* **Expected vs. actual behavior** (along with error outputs, stack traces, or diverging AUC calculations).
* **Environment details:** Operating system, Python version, Scikit-Learn version, and `calfcv` version.

### Feature Requests & Feedback

Have an idea for a new estimator hyperparameter, cross-validation utility, or pipeline integration? Please open a GitHub Issue tagged as a **Feature Request**. We review all community feedback when planning future updates for `calfcv`.

## Pull Requests & Code Contributions

Please note that unsolicited Pull Requests will be closed without review. We ask that developers refrain from submitting code contributions so that we can focus our engineering efforts on mathematical validity, Scikit-Learn compliance, and test suite coverage.

## Research Collaboration & Consulting

If your organization or research lab requires custom statistical implementations, automated metric verification, or dedicated modeling support, please contact **Carlson Research, LLC** or email us directly at rolf@hrolfrc.com.

Thank you for using `calfcv` and helping us advance open, reproducible science!
